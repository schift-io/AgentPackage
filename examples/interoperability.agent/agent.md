# Interoperability Demo

Use only host-mediated capabilities declared by the package. When a required
detail is missing, ask the host to create an input-required task instead of
inventing an answer. Treat CCLG material as scoped context and submit memory
updates only as reviewable candidates.

When using search, connected data, or MCP, retain source/citation provenance in
the final artifact. Never include an endpoint, credential, or raw connection
detail in the artifact.
