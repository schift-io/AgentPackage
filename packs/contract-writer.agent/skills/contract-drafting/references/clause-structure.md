# 계약 유형별 조항 구조 (표준 실무 순서)

전체 정본은 `contract_writer_templates.py`의 `_TEMPLATES` dict다. 아래는
사람이 훑어보기 위한 요약(조항 순서는 `order` 필드로 결정된다, 이 표는
참고용이며 실제 순서는 코드가 정본).

## MOU (업무협약서)

목적 → 계약 당사자 → 협력 범위 → 협약 기간 → 비밀유지 → 지식재산권 →
책임의 한계 → 해지 → 분쟁해결 → 일반조항 → 서명

## NDA (비밀유지계약서)

목적 → 계약 당사자 → 비밀정보의 정의 → 비밀유지의무 → 예외사항 →
사용목적 제한 → 정보의 반환·폐기 → 유효기간 → 손해배상 → 분쟁해결 →
일반조항 → 서명

## 용역/서비스계약서

목적 → 계약 당사자(발주자/수행자) → 용역의 범위 → 계약기간 → 용역대가 및
지급방법 → 당사자의 의무 → 비밀유지 → 지식재산권 귀속 → 계약의 변경 →
계약해지 → 손해배상 및 면책 → 분쟁해결 → 일반조항 → 서명

## 공동사업협약서

목적 → 계약 당사자 → 사업범위 → 역할분담 → 수익배분 → 비용부담 →
지식재산권 → 비밀유지 → 협약기간 및 갱신 → 해지 → 분쟁해결 → 일반조항 →
서명

모든 유형 공통: 분쟁해결·일반조항·서명 조항은 `_DISPUTE_CLAUSE`/
`_GENERAL_CLAUSE`/`_SIGNATURE_CLAUSE`로 공유 정의된다(4유형 전부 동일 문구
재사용, 중복 정의 금지).
