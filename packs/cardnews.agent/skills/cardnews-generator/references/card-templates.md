# 카드뉴스 템플릿 레퍼런스

카드뉴스 작성 시 참조하는 **검증된 구성 템플릿 + 훅 공식 + 레이아웃 규칙**.
뼈대(구조)는 이 레퍼런스를 따르고, 색·폰트·문구만 주제에 맞게 채운다.
출처 관례: Canva / 망고보드 / Pixso 등 카드뉴스 제작 가이드 공통 패턴.

---

## 1. 검증된 8장 구성 템플릿 (목적별)

### A. 홍보·모집형 (학원·매장·이벤트) — 가장 범용
1. **훅** — 타깃의 고민/욕구 1문장 (숫자·질문·반전)
2. **공감** — "왜 이게 당신 얘기인가"
3. **해결 제시** — 우리가 뭘 해주는지 한 줄
4. **차별점 1** — 다른 곳과 다른 점 (숫자로)
5. **차별점 2 / 방법** — 어떻게 하는지
6. **증거** — 후기·수치·전후 비교 (근거 있는 것만)
7. **요약** — 본문을 1장으로 압축, 저장 유도
8. **End / 브랜드 클로징** — `brand_kit`/입력 메모리에 제공된 고객 로고와 태그라인, 단일 행동, URL/핸들

### B. 정보·꿀팁형 ("~하는 N가지 방법")
1. 훅(숫자 제목: "여름방학 영어 3가지 방법") → 2~7. 팁 1개/장 → 8. 제공된 브랜드 요소로 팔로우 유도

### C. 스토리·후기형
1. 훅(반전/고백) → 2. 문제 상황 → 3~5. 변화 과정 → 6. 결과(수치) → 7. 한 줄 메시지 → 8. 브랜드 클로징

> 카드 수는 6~10장 유연. 정보가 많으면 1장 추가보다 **메시지를 쪼개기**.

## 2. 1장(훅) 공식 — 정지율이 전부

- **숫자형**: "한 반 6명, 이유가 있어요"
- **질문형**: "여름방학, 아이 영어 이대로 둬도 될까요?"
- **반전형**: "학원 많이 보낸다고 영어 늘지 않아요"
- **고백형**: "솔직히 대형학원 보내고 후회했어요"
- 훅은 **대안 2개 이상** 써보고 정지율 비교 후 택1, 이유 기록.

## 3. 카드당 카피 규칙

- **1카드 = 메시지 1개.** 소리 내어 7초 이내 분량.
- 헤드라인 2줄 이내(굵게) + 보조 1~2줄. 카드 폭의 60%+를 헤드라인이 차지.
- 숫자를 전진 배치(기간·정원·비율·후기 수) — 단 근거 있는 것만.
- AI 티/과장어 금지(혁신적·압도적·최고의). 마침표 남발 금지 — 짧게 끊기.
- 채널 톤: 인스타·스레드 구어체(반말 또는 ~요체 통일), 공식 브랜드는 차분한 ~요체.

## 4. 레이아웃·타이포 규칙

- 규격: 인스타 세로 **1080×1350** 기본 / 정방형 **1080×1080**은 사용자가 명시할 때만.
- 모바일 가독성 최우선 — 큰 글자, 여백 충분, 4px 그리드.
- 이미지형 카드뉴스는 **full-bleed 이미지 + 블랙 오버레이 + 텍스트 오버레이**를 기본값으로 한다.
- 카드마다 `이미지:` 지시를 두고, 최종 렌더에는 1080×1350 배경으로 버틸 수 있는 고해상도 소재만 사용한다. 썸네일/작은 SNS preview/크롤러 preview는 후보에서 제외한다.
- 위/아래 안전 여백은 최소 96px. 진행 표시와 출처 캡션도 가장자리에서 띄운다.
- 한 카드 장식 요소 1개 이하. 색은 팔레트 1조합만(`../deck-designer/references/color-palettes.md`).
- 우하단 진행 표시(예: `3/8`). 텍스트/배경 WCAG AA 대비.
- 아이콘·일러스트 필요 시 3dicons.co(CC0) 또는 단색 outline SVG.

## 5. End / CTA 규칙

- 마지막 1장, **브랜드 클로징 카드**. `brand_kit` 또는 입력 메모리에 제공된 회사 로고, 짧은 태그라인, 행동 1개, URL/핸들만 둔다. 제공되지 않은 로고·URL·핸들은 지어내지 않는다.
- End 카드는 새 정보 카드가 아니다. 앞 내용을 재요약해 브랜드 기억으로 닫는다.
- CTA는 "지금 전화 주세요(031-...)"처럼 행동 + 수단으로 1개만 둔다.
- CTA 2개 이상 금지. 해시태그는 캡션에, 카드 안엔 최소.

## 6. 제작 체크리스트

- [ ] 1장 훅 대안 2개+선택 이유
- [ ] 카드당 메시지 1개
- [ ] 모든 수치에 근거(없으면 "문의 시 안내")
- [ ] 색 1조합 / 진행 표시 / AA 대비
- [ ] End 카드에 제공된 고객 로고 + 태그라인 + 단일 CTA + URL/핸들만 사용
- [ ] 채널별 캡션·게시 시간
