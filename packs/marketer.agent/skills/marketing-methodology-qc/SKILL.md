# 마케팅 방법론 검증 (Marketing Methodology QC)

> 목적: "문장이 매끄러운가"가 아니라 **"이 글이 마케팅적으로 작동하는가"**를 검증한다.
> 검증자는 카피라이팅·퍼포먼스 마케팅 이론을 기준으로 판정한다.

## 판정 프레임 (체크리스트)

1. **카피 구조 (AIDA / PAS)**
   - AIDA: Attention(훅) → Interest(공감/문제) → Desire(차별점·증거) → Action(CTA) 흐름이 있는가.
   - PAS: Problem(문제) → Agitate(자극·확대) → Solution(해결) 중 하나의 골격을 따르는가.
   - 구조 없이 정보만 나열돼 있으면 S1(반드시 수정).

2. **훅 강도 (첫 문장/첫 카드)**
   - 3초 안에 멈추게 하는가. 숫자·질문·반전·구체적 상황 중 하나를 쓰는가.
   - "안녕하세요 ○○입니다" 같은 약한 도입은 S1.

3. **타깃-채널 적합성**
   - 채널 관습에 맞는가. 네이버 블로그=검색 의도+소제목, 스레드=짧은 구어체+훅, 링크드인=전문가 톤+인사이트, 카드뉴스=1카드 1메시지, 포스터=한 장에 핵심 1개.
   - 타깃(학부모/사장님/B2B 담당자)의 언어로 말하는가.

4. **브랜드 키트 일관성**
   - 브랜드명·로고·핵심 색·URL·핸들이 세션 `brand_kit` 또는 입력 메모리에서 온 값인가.
   - 제공되지 않은 로고·URL·핸들을 지어냈거나 플랫폼 기본값으로 대체했으면 S1.
   - 카드뉴스/포스터처럼 시각 산출물이면 CSS 변수·End 카드·CTA가 동일한 고객 브랜드를 따르는지 본다.

5. **단일 CTA**
   - 다음 행동이 1개로 명확한가(전화/방문/등록/팔로우/문의). CTA가 0개거나 2개 이상이면 S2.

6. **증거 (구체성 + 청중 관점)**
   - 구체적인 숫자(기간·인원·비율·후기 수)나 실제 후기가 있는가. "많은", "최고의" 같은 공허한 표현으로 때우지 않는가.
   - **근거 없는 수치(지어낸 합격률·금액)는 S1** — 삭제하거나 "문의 시 안내" 가드로.
   - **청중 관점 우선 (중요)**: 청중이 *원하는 결과*를 앞세웠는가, 아니면 *우리 입장의 지표*를 박았는가?
     - 학부모 타깃인데 "재등록률 87.5%", "만족도 설문" 같은 **우리 비즈니스 KPI를 훅·제목에 박으면 S2**. 학부모가 원하는 건 "내 아이가 어떻게 달라지나"(성적·자신감·스스로 책 펴는 습관)다.
     - 사회적 증거(재등록·후기)는 버리지 말되 **청중 언어로 번역**해 보조로 내린다: "21명이 다시 왔어요" → "그만큼 아이들이 진짜 달라졌다는 뜻이에요". 훅은 아이의 변화·후기로 연다.
     - B2B(링크드인)는 청중이 원하는 결과 = ROI·리스크 감소·구체적 성과. 거기에 맞춘 지표면 OK.

7. **AI 티 (Humanize)**
   - 번역체(~를 통해), AI 관용구(결론적으로/시사하는 바가 크다), 과장어(혁신적/압도적/완벽한), 기계적 병렬(첫째/둘째), 이모지 남발이 있는가. 있으면 S2.
   - **모든 문장이 마침표로 똑같이 끝나는가** ㅡ 그러면 AI 티. 한국어 글은 마침표 절제 + 줄바꿈/'ㅡ'/'~'로 호흡을 살려야 한다. 마침표 일변도면 S2로 잡아 고친다.
   - 링크드인인데 까닭 없이 영어로 쓰여 있으면 S1(국내 타깃 기본 한국어).

## 출력

- `grade`: A~D (구조·훅·브랜드 키트·CTA·증거·AI티 종합).
- `framework`: 이 글이 따른 구조(AIDA/PAS/기타).
- `findings`: [{severity(S1/S2/S3), axis(구조/훅/채널/브랜드/CTA/증거/AI티), where, why, fix}].
- `unresolved`: 근거가 없어 유저 확인이 필요한 수치/주장.
- 결정: `ship` / `revise`(권장 수정 반영) / `hold`(S1 잔존 — 유저 확인 필요).
