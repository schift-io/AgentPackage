# Landing-page Brief and Copy

Create `artifacts/landing-page-brief.md` from the shared brief. This is a content brief and copy draft, not a website deployment.

Use this structure:

```markdown
# Landing-page Brief

- page objective:
- primary audience:
- primary action:
- shared-brief revision:

## Message hierarchy
1. headline:
2. supporting promise:
3. proof points and source fields:
4. primary CTA:

## Section plan and draft copy
### Hero
...

### Problem / value / proof / CTA
...

## Claim and publication review flags
- [ ] Every factual claim is sourced in the shared brief
- [ ] Legal, pricing, and approval-sensitive copy is reviewed
- [ ] Human approval is required before publication
```

Rules:

- Make one user-facing promise and one primary action clear before adding secondary content.
- Do not invent customer logos, testimonials, performance metrics, pricing, availability, or legal/compliance claims.
- Keep unknown proof as `needs_confirmation`, not as finished marketing copy.
- A later landing-page runtime adapter may implement or publish approved copy; no adapter is embedded here.
