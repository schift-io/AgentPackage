# Business Plan and Proposal Structure

Create `artifacts/proposal-structure.md` as a grounded structure for a business plan, internal decision document, or external proposal. It is a drafting scaffold, not a submission.

Use this structure:

```markdown
# Proposal Structure

- purpose:
- audience/evaluator:
- shared-brief revision:

## 1. Problem and context
- claim:
- evidence / source fields:

## 2. Proposed approach
...

## 3. Delivery plan, ownership, and risks
...

## 4. Expected value and decision request
...

## Evidence gaps and review flags
```

Rules:

- Adapt the section order to a user-provided template or evaluation criteria. If none is supplied, use the structure above.
- Separate confirmed facts from assumptions, estimates, and targets.
- Do not fabricate budgets, revenue, market size, schedules, customer names, approvals, or compliance claims.
- A later business-plan runtime adapter may format an approved structure; no adapter is embedded here.
