# Email Drafts and Follow-ups

Create `artifacts/email-draft.md` from the current shared brief. This is a reviewable text draft, not a mailbox action.

Use this structure:

```markdown
# Email Draft

- purpose:
- audience/recipient role:
- shared-brief revision:
- facts used:

## Subject options
1. ...

## Draft body
...

## Follow-up plan
- trigger/date: [needs_confirmation unless supplied]
- proposed follow-up:

## Review flags
- [ ] Recipient and address confirmed by a human
- [ ] Claims and commitments match the shared brief
- [ ] Human approval is required before send
```

Rules:

- Use only confirmed shared-brief facts. Phrase unconfirmed matters as a question or `needs_confirmation`, never as a commitment.
- Do not include an email address unless it is supplied in the shared brief.
- Never send, schedule, save to a mailbox, or imply that a message was sent.
- Escalate legal, pricing, security, personnel, contractual, or public commitments to the review checklist.
