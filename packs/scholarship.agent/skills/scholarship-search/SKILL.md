# 장학금 검색 (Scholarship Search) — 베타

> 핵심 명제: **장학금 정보는 출처가 전부다. 공식 공고로 검증 안 된 금액·기간·자격은 잘못된 정보보다 위험하다.**
> 두 번째 명제: **학생이 다이제스트를 보고 "지금 뭘 신청하면 되는지" 5초 안에 알 수 있어야 한다.**

## 1. 검색 흐름 (순서 고정)

1. **한국장학재단(kosaf.go.kr) 전국 단위** 공고부터. 국가장학금, 국가근로, 학자금대출, 우수장학금 등.
2. **학교 지정 시** 그 학교 공식 도메인(`*.ac.kr`)에서: 학교 본부 → 학생지원처/장학복지 → 단과대 → 학과 순으로 교내·교외 장학 공지.
3. **재단·기업·공공기관**: `*.or.kr`, `*.go.kr` 공식 페이지. 대표 재단(삼성·현대·LG·아산·관정 등)과 지자체 공고.
4. 각 공고에서 **금액·자격·지원구간·신청기간·공식 링크·신청 링크**를 정규화해 뽑는다.
5. 상태 분류 + 적격성 판정 + 다이제스트 정렬.

## 2. 출처 규칙 (가장 중요)

- **공식 도메인만 결과로 인정**: `kosaf.go.kr`, `*.ac.kr`, `*.go.kr`, `*.or.kr`.
- 블로그·네이버 카페·티스토리·유튜브 등은 **리드(단서)로만** 사용한다. 공식 공고 URL로 교차검증되지 않으면 결과에서 **뺀다**.
- 한 장학금이 여러 출처에 보이면 **가장 공식적인 출처 하나**로 합치고 나머지는 버린다.
- URL은 실제 검색 결과로 확인된 것만 적는다. **링크를 추측해서 만들지 않는다.**

## 3. 추출 필드 (공고당)

| 필드 | 설명 |
|------|------|
| 장학금명 | 공식 명칭 그대로 |
| 기관/유형 | 한국장학재단 / 교내 / 재단 / 기업 / 공공기관 |
| 금액 | 확인된 지원액. 구간이면 범위. 불명 시 [확인 필요] |
| 자격요건 | 학교·학년·전공·GPA·소득분위·기타 조건 |
| 신청기간 | 시작~마감 (KST). 불명 시 [기간 확인 필요] |
| 상태 | 지금 지원 가능 / 곧 열림 / 마감됨 |
| 공식 링크 | 공고 원문 URL |
| 신청 링크 | 신청 페이지 URL (없으면 공식 링크) |

## 4. 상태 분류 (KST 기준, 오늘 날짜 대비)

- **지금 지원 가능**: 시작일 ≤ 오늘 ≤ 마감일.
- **곧 열림**: 오늘 < 시작일 (시작 예정).
- **마감됨**: 마감일 < 오늘.
- **마감 임박**: 지금 지원 가능 중 마감까지 ≤ 7일 → 다이제스트 최상단 별도 그룹.
- 날짜가 불확실하면 단정하지 말고 `[기간 확인 필요]`로 두고 "곧 열림/지원 가능" 사이로 보수적으로 둔다.

> **마감일 우선 규칙 (절대):** 분류는 오직 **마감일 vs 오늘** 비교로만 한다.
> "2026년 1학기"·"현재 학기" 같은 **학기 라벨에 속지 말 것** — 마감일이 오늘보다 과거면
> 학기가 진행 중이어도 무조건 **마감됨**이다. (예: 오늘 2026-06-14인데 신청기간이
> 2025.11.20~2025.12.26이면 → 마감됨. "2026년 1학기"라서 지원 가능 아님.)
> 마감 임박(D-7)도 **마감일이 오늘 이후**일 때만 붙인다. "예정"·"미정" 기간엔 임박을
> 붙이지 말고 `곧 열림` 또는 `[기간 확인 필요]`로 둔다.

## 5. 적격성 판정 (학생 조건이 주어졌을 때)

- 학생 입력(학교·학년·전공·GPA·소득분위)과 공고 자격요건을 1:1 대조한다.
- 명확히 충족 → `✅ 지원 가능`, 명확히 불충족 → `❌ 대상 아님(사유)`, 애매 → `⚠️ 본인 확인 필요(쟁점)`.
- **확실하지 않으면 절대 "지원 가능"으로 단정하지 않는다.** 학생이 잘못 믿고 마감 놓치는 게 최악.

## 6. 다이제스트 출력 형식

```
📋 장학금 다이제스트 — {날짜 KST} / 기준: {학생 조건 요약}

요약: 총 {N}건 · 지금 지원 가능 {a} · 곧 열림 {b} · 마감 임박 {c}

⏰ 마감 임박 (D-7 이내)
  - {장학금명} · {기관/유형} · {금액} · ~{마감일}(D-{n}) · {적격성}
    공식: {url}  신청: {url}

🟢 지금 지원 가능
  - ...

🔵 곧 열림
  - ...

(마감됨은 기본 접어두고, 요청 시만 펼친다)

⚠️ 사람 확인 필요
  - {불확실한 기간/금액/자격, 미검증 출처}
```

## 7. 하지 않는 것

- 자동 신청·자동 제출 금지. "어디에 무엇을 신청"까지만 안내한다.
- 출처 없는 금액·기간·자격 생성 금지.
- 학생 소득분위·성적 같은 개인정보를 결과 본문에 그대로 노출하지 않는다 (조건 요약만).

## 8. 정기 다이제스트(cron) 모드

- cron으로 호출되면 저장된 학생 조건(프로필)으로 위 흐름을 1회 실행해 다이제스트를 만든다.
- **MVP**: 매 실행 라이브 웹검색 → 전체 다이제스트. "새 공고만"은 보장하지 않으므로 상태·마감 임박으로 신호를 준다.
- **승격(추후)**: 직전 실행 결과와 diff해 "새로 열린 공고"만 강조. 이때 크롤러+버킷 적재로 전환한다.
