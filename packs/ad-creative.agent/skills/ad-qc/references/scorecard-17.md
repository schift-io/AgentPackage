# 17-Point Creative Scorecard

렌더 전·출시 전 두 번 건다. 항목별 배점 합 17점.

| 항목 | 배점 | 기준 |
|------|------|------|
| Hook | 0-2 | 첫 1~2초 스크롤 정지력 |
| Pain | 0-2 | 타깃 문제를 정확히 건드리는가 |
| Value clarity | 0-2 | 가치가 명확한가 |
| Proof | 0-2 | 증거(데이터·후기·시연)가 있는가 |
| Offer | 0-1 | 제안이 구체적인가 |
| Urgency | 0-1 | 지금 행동할 이유가 있는가 |
| CTA | 0-2 | 다음 행동이 명확한가 |
| Differentiation | 0-1 | 경쟁 대비 차별점이 보이는가 |
| Emotional resonance | 0-1 | `must_feel`을 실제로 유발하는가 |
| Platform fit | 0-1 | 채널·비율·길이에 맞는가 |
| Audience/Cultural fit | 0-2 | 세그먼트 어투·맥락에 맞는가 |

## 임계값
- **15~17**: ship
- **12~14**: solid — 약한 항목만 보완
- **9~11**: rework — 앵글/카피 재작업
- **<9**: 근본 재작업 — 브리프로 복귀

## 규칙
- 6요소(`six-element-ontology.md`) 커버리지가 비면 점수와 무관하게 **자동 rework**.
- "Audience/Cultural fit"은 세그먼트 `real_quotes`·감정 드라이버 기준으로 채점(진부한 카피 감점).
- 진부표현("친근한/신뢰할 수 있는")·보고체·AI slop은 Emotional/Culture fit에서 감점.
