# Startup-support APM 필수 표식 체크리스트

최종 HTML 아티팩트가 APM 매니페스트 QC 계약을 통과하려면 아래 문구가 반드시 본문에 포함되어야 한다. 각 문구의 **추천 위치**를 참고해 빠짐없이 남긴다.

## 1. HTML 아티팩트

- **문구:** `HTML 아티팩트`
- **위치:** `<h1>` 제목 옆 또는 HTML 주석 `<!-- HTML 아티팩트 -->`로 최상단에 표기.
- **예시:** `<h1>HTML 아티팩트: 지원사업 큐레이션 및 사업계획서 초안</h1>`

## 2. 공식 링크

- **문구:** `공식 링크`
- **위치:** `2. 공고 후보` 표의 마지막 열 제목.
- **예시:**

  ```html
  <table>
    <thead>
      <tr><th>사업명</th><th>기관</th><th>상태</th><th>신청기간</th><th>지원규모</th><th>핵심 자격</th><th>공식 링크</th></tr>
    </thead>
    ...
  </table>
  ```

## 3. 공고 평가항목

- **문구:** `공고 평가항목`
- **위치:** `3. 적합도 판단`의 추천 사유 셀 안에서, 또는 5-0~5-4 본문에서 selected_notice의 평가 기준을 언급할 때.
- **예시:** `<br><strong>공고 평가항목:</strong> 기술경쟁력, 사업화 가능성, 팀 구성.`

## 4. 캘린더 후보

- **문구:** `캘린더 후보`
- **위치:** `4. 일정과 알림` 섹션의 제목, 부제목, 표 제목, 또는 첫 문단에 반드시 한 번 이상.
- **예시:**
  - `<h2>4. 일정과 알림</h2>` 아래 `<p>선정된 사업을 기준으로 캘린더 후보 일정을 설정합니다.</p>`
  - 표 제목: `<h3>캘린더 후보</h3>`

## 5. 사업계획서 섹션 표식

- **문구:** `사업개요 요약`, `문제인식`, `실현가능성`, `성장전략`, `팀 구성`, `도식 초안`
- **위치:**
  - `사업개요 요약`은 `5-0` 절 제목 또는 본문.
  - `문제인식`, `실현가능성`, `성장전략`, `팀 구성`은 각 5-1~5-4 절 제목.
  - `도식 초안`은 5-0~5-4 각 하위 절에 한 번 이상.

## 6. 회사 근거

- **문구:** `회사 근거`
- **위치:**
  - `5-4 팀 구성 및 증빙` 절 제목, 표 제목, 또는 표/본문 내용 중 한 곳.
  - `3. 적합도 판단`의 회사 조건 근거를 정리한 표 제목에도 사용 가능.
- **예시:** `<h3>5-4 팀 구성 및 회사 근거</h3>` 또는 `<th>회사 근거</th>`

## 7. 창업자 의사결정

- **문구:** `창업자 의사결정`
- **위치:** 최종 섹션 제목 또는 본문. `6. 제출 전 확인사항` 다음에 별도 `<h2>`로 배치.
- **예시:** `<h2>창업자 의사결정</h2>`

## 8. 제출 전 확인

- **문구:** `제출 전 확인`
- **위치:** `6. 제출 전 확인사항` 제목, 본문, 체크리스트 항목 중 한 곳 이상.
- **예시:** `<h2>6. 제출 전 확인사항</h2>`

## 9. 최종 출력 전 자동 점검

HTML 아티팩트를 완성하기 전에 아래 문구가 모두 있는지 빠르게 확인한다.

- [ ] `HTML 아티팩트`
- [ ] `공식 링크`
- [ ] `공고 평가항목`
- [ ] `캘린더 후보`
- [ ] `사업개요 요약`
- [ ] `문제인식`
- [ ] `실현가능성`
- [ ] `성장전략`
- [ ] `팀 구성`
- [ ] `도식 초안`
- [ ] `회사 근거`
- [ ] `창업자 의사결정`
- [ ] `제출 전 확인`

위 문구 중 하나라도 없으면 QC가 실패할 수 있다. 단, 각 문구는 본문 맥락에 맞게 자연스럽게 삽입해야 하며, 단순히 나열하지 않는다.
