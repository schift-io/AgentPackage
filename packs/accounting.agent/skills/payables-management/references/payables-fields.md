# 미지급금(AP) 관리 · 지급 일정 필드 명세 (Room821 자체 양식)

기업마당(bizinfo) 무료 서식의 매입 관리 양식(세금계산서 관리대장·매입처별 거래명세서
내역표)을 rhwp/openpyxl로 열어 실제 필드를 확인하고 재구성한 우리 양식. document-helper가
hwpx/html로 렌더링할 때 이 필드를 채운다. **외부 파일을 그대로 쓰지 않고 항목/구조만
참고해 새로 만든다.**

## 1. 매입처별 지급 대상 정리 (세금계산서 관리대장 — 매입 기준)

실측: 세금계산서 관리대장(매입) = 부서 · 작성자 · 매입[일자·매입처(업체명)·품목·공급가액·부가세·합계] · 매입 합계.

매입처별로 묶어 지급 대상을 집계한다.

| 필드 | 설명 | 비고 |
|------|------|------|
| 매입처(업체명) | 거래처 상호 | 사업자번호와 함께 식별 |
| 사업자등록번호 | 거래처 사업자번호 | 적격증빙은 사업자번호 확인, 끝 4자리만 노출 |
| 작성일자 | 세금계산서 작성일자 | 결제조건 기산일 |
| 품목 | 매입 품목/내용 | |
| 공급가액 | 부가세 제외 금액 | |
| 세액(부가세) | | 면세/불공제 표시 |
| 합계 | 공급가액 + 세액 | 자동 합산 |
| 매입처별 소계 | 거래처 단위 합계 | 매입세금계산서 건수 + 매입금액총액 |

## 2. 매입처별 거래명세 내역 (매입처별 거래명세서 내역표)

실측: 매입처별 거래명세서 내역표 = 기간 · 거래처명 · 매입세금계산서 건수 · 매입금액총액 · [일자·품목·수량·단가·공급가액·세액·합계].

| 필드 | 설명 |
|------|------|
| 기간 | 집계 대상 기간 |
| 거래처명 | 매입처 |
| 매입세금계산서 건수 | 거래처별 건수 |
| 매입금액총액 | 거래처별 합계 |
| 일자 / 품목 / 수량 / 단가 / 공급가액 / 세액 / 합계 | 건별 명세 |

## 3. 미지급금(AP) 관리 스키마 (행 단위 — 핵심 산출)

지급 대상·일정·알람·완료를 한 표에서 추적한다.

| 필드 | 설명 | 처리 |
|------|------|------|
| 거래처 | 상호 + 사업자등록번호 | 사업자번호 끝 4자리만 노출 |
| 세금계산서 작성일자 | 매입 세금계산서 작성일 | 결제조건 기산일 |
| 품목 | 매입 품목/내용 | |
| 공급가액 | 부가세 제외 금액 | |
| 세액 | 부가세 | 면세/불공제 표시 |
| 합계 | 공급가액 + 세액 | 자동 합산 |
| 결제조건(기일) | 익월 말 / 30일 / 계약조건 등 | 없으면 [확인 필요], 임의 가정 금지 |
| 지급예정일 | 작성일자 + 결제조건으로 산출 | 결제조건 불명확 시 [확인 필요] |
| 지급상태 | 예정 / 완료 / 연체 | 사람이 표시한 값을 진실로 삼음 |
| 증빙구분 | 세금계산서/계산서/청구서/거래명세서/기타 | 적격 여부 |
| 부가세공제 | 공제 / 불공제 | 불공제 사유 |
| 비고 | 충돌·누락·확인필요·Bolta 핸드오프 메모 | |

## 4. 지급 일정표 · 알람 규칙

### 지급 알람 규칙

- **지급예정일 D-3**: 지급 임박 건을 예정 알람 목록에 올린다 (기본값, intake에서 조정 가능).
- **지급예정일 D-0**: 당일 지급 대상.
- **지급예정일 경과 + 완료 표시 없음 → 연체**: 자동으로 지급상태를 연체로 표시.
- 알람은 목록만 만든다. **실제 이체·결제는 사람 승인·실행** (자동 side-effect 금지).

### 지급 예정 알람 목록 (산출 컬럼)

| 거래처 | 합계 | 결제조건 | 지급예정일 | D-day | 지급상태 | 증빙구분 | 비고 |
|--------|------|----------|------------|-------|----------|----------|------|
| … | … | 익월 말 | 2026-06-30 | D-3 | 예정 | 세금계산서 | |
| … | … | [확인 필요] | [확인 필요] | — | 예정 | 청구서 | 결제조건 확인 필요 |
| … | … | 30일 | 2026-06-10 | 경과 | 연체 | 세금계산서 | 완료 표시 없음 → 연체 |

## 5. 합계 요약 (관리대장형)

- 공급가액 합계 / 세액 합계 / 매입 총액
- 매입처별 미지급금 소계 (거래처 단위 잔액)
- 지급상태별 집계: 지급예정 합계 / 지급완료 합계 / 연체 합계
- 기간별(월별) 미지급금 추이
- 적격증빙 합계 / 비적격증빙 합계, 부가세 공제대상 합계 / 불공제 합계

## 6. 적격증빙 · 부가세 매입공제 점검

- 적격증빙(세금계산서·계산서·카드매출전표·현금영수증)과 비적격을 구분한다.
- 매입세액 공제/불공제를 거래마다 판단한다. **공제 기준은 `accounting-kr-tax-reference`
  버킷(schift-rag)을 먼저 검색**하고, 검색된 근거를 공제 판단에 함께 남긴다.
- 부가세 불공제 항목(접대비·비영업용 승용차·면세·간이/면세사업자 발행분)은 표시한다.
- 적격증빙이 없는 매입은 [확인 필요]로 표시하고, 필요 시 거래처에 증빙 요청 대상으로 남긴다.

## 7. Bolta 핸드오프 (발행 필요분)

- **세금계산서 발행/역발행은 Bolta API 연동이 담당한다. 자체 발행 구현 금지.**
- 매입 증빙이 누락됐거나 역발행이 필요한 건은 **Bolta 핸드오프**로 표시한다.

| 거래처 | 합계 | 발행 사유 | 핸드오프 대상 | 비고 |
|--------|------|-----------|----------------|------|
| … | … | 세금계산서 미수취 | Bolta (역발행 요청) | |
| … | … | 발행 누락 | Bolta | |

## 8. 지급 전 검수 체크 (사람 확인)

- [ ] 매입 증빙(세금계산서/청구서) 원본과 관리본 금액·일자·거래처 일치
- [ ] 결제조건·지급예정일 산출 근거 확인 (불명확 건 [확인 필요] 처리)
- [ ] 지급상태(예정/완료/연체) 표시가 실제 이체 내역과 일치
- [ ] 적격증빙 확보 / 부가세 매입공제·불공제 표시 적정
- [ ] 발행 필요분 Bolta 핸드오프 표시 (자체 발행 안 함)
- [ ] 중복·누락 매입 건 없음
- [ ] **실제 계좌이체·대금 지급은 담당자 승인 후 사람이 실행** (자동 이체 아님)
