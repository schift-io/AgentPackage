# 부가가치세 신고서 칸 명세 (일반과세자)

부가가치세법 시행규칙 **[별지 제21호서식] 일반과세자 부가가치세 신고서**(출처:
law.go.kr, 개정 2019.2.11) 기준의 칸 정의와, 표준 거래내역 → 신고서 칸 매핑·집계·
공제/불공제 점검 명세. 매입세액 공제/불공제 판단 기준은 `accounting-kr-tax-reference`
버킷이 정본이며, 여기서는 서식의 칸 구조와 신고 단위 집계만 정의한다. 회사별 사정과
다를 수 있고, 최종 신고서 작성·전자신고는 홈택스/세무대리인이 한다.

## 1. ❶ 신고내용 — 과세표준 및 매출세액

칸 번호는 서식 그대로. 세율 칸은 과세표준(공급가액) × 세율 = 세액.

| 칸 | 항목 | 세율 | 표준 거래내역 매핑 |
|----|------|------|---------------------|
| (1) | 과세 — 세금계산서 발급분 | 10/100 | 매출 세금계산서 발급분 공급가액·세액 |
| (2) | 과세 — 매입자발행 세금계산서 | 10/100 | 매입자발행 세금계산서 매출분 |
| (3) | 과세 — 신용카드·현금영수증 발행분 | 10/100 | 카드매출전표·현금영수증 발행 매출 |
| (4) | 과세 — 기타(정규영수증 외 매출분) | 10/100 | 증빙 없는 현금매출 등 |
| (5) | 영세율 — 세금계산서 발급분 | 0/100 | 영세율 세금계산서 발급분 |
| (6) | 영세율 — 기타 | 0/100 | 수출 등 영세율 기타 |
| (7) | 예정신고 누락분 | | 예정신고에서 빠진 매출 (확정 시) |
| (8) | 대손세액 가감 | | 대손 확정/회수분 (±) |
| (9) | 합계 | | (1)~(8) 매출세액 합계 = **매출세액** |

## 2. ❶ 신고내용 — 매입세액

| 칸 | 항목 | 표준 거래내역 매핑 |
|----|------|---------------------|
| (10) | 세금계산서 수취분 — 일반매입 | 매입 세금계산서(일반) 공급가액·세액 |
| (10-1) | 세금계산서 수취분 — 수출기업 수입분 납부유예 | 해당 시에만 |
| (11) | 세금계산서 수취분 — 고정자산 매입 | 고정자산(설비·차량 등) 매입 세금계산서 |
| (12) | 예정신고 누락분 | 예정신고에서 빠진 매입 (확정 시) |
| (13) | 매입자발행 세금계산서 | 매입자발행분 |
| (14) | 그 밖의 공제매입세액 | 카드·현금영수증 매입, 의제매입 등 공제분 |
| (15) | 합계 | (10)~(14) 합계 |

**납부(환급)세액 = 매출세액(9) − 매입세액(17).** 음수면 환급.

## 4. 매입세액 공제/불공제 점검 (사람 확인)

매입 거래마다 공제/불공제를 판단하고, 불공제는 **공제받지 못할 매입세액(16)** 으로
분리한다. 판단 근거는 `accounting-kr-tax-reference` 버킷 검색 결과를 함께 남긴다.

- [ ] 접대비 관련 매입세액 → **불공제**
- [ ] 비영업용 소형승용차 구입·임차·유지 관련 → **불공제**
- [ ] 면세사업 관련 매입·토지 관련 매입 → **불공제**
- [ ] 사업과 직접 관련 없는 지출 → **불공제**
- [ ] 세금계산서 미수취·필요적 기재사항 누락 → **불공제**
- [ ] 간이·면세사업자 발행분(매입세액 없음) → 공제 대상 아님
- [ ] 카드·현금영수증 매입은 적격 수취·사업관련 확인 후 (14) 공제 반영
- [ ] 고정자산 매입은 (11)로 분리했는지 확인

각 항목은 거래 건과 금액·사유를 함께 표기하고, 애매하면 후보 2개 + [확인 필요].

## 6. 집계·검산 규칙

- 매출: (1)~(6) 칸별 공급가액·세액을 표준 거래내역의 증빙구분(세금계산서/카드·현금
  영수증/기타)·영세율 여부로 분류해 합산한다. 예정신고 누락분(7)·대손(8) 가감 후 (9).
- 매입: 세금계산서 수취분(일반 10/고정자산 11)·기타공제(14)를 합쳐 (15), 불공제(16)를
  빼서 차감계(17). 카드·현금영수증 매입은 적격·사업관련 확인 후 (14)에 반영.
- 세금계산서 합계표 합계 ↔ 신고서 (1)·(5)·(10)·(11) 합계가 일치하는지 검산한다.
- 카드·현금영수증 발행 합계 ↔ (3) / 매입 ↔ (14)·(19) 정합성 확인.
- 과세표준 명세(28~32) 금액 합계 ↔ (9) 과세표준 일치 검산.

## 7. 제출 전 검수 체크 (사람 확인)

- [ ] 과세기간(1기/2기·예정/확정)과 신고 마감일이 맞는가
- [ ] 매출 과세·영세율·카드·현금영수증·기타 분류가 칸별로 맞는가
- [ ] 세금계산서 합계표 합계 ↔ 신고서 칸 합계 일치(검산)
- [ ] 매입세액 공제/불공제 판단 적정 — 불공제(16)에 접대비·승용차·면세 등 분리
- [ ] 고정자산 매입(11)·예정신고 누락분(7·12)·대손(8) 반영 확인
- [ ] 예정고지세액(22)·경감공제(18·19)·가산세(26) 반영
- [ ] 납부(환급)세액(27) 재계산이 매출세액 − 매입세액과 일치
- [ ] 환급 시 환급 계좌(❷), 과세표준 명세(❹) 작성
- [ ] 사업자등록번호·계좌번호 마스킹 적용
- [ ] **신고서 작성·전자신고는 홈택스/세무대리인의 몫** — 이 산출물은 참고용 초안,
      신고 전 세무대리인 검토 필수
