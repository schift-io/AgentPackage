# 미수금 관리 데이터 명세 (Room821 자체 정의)

매출·입금 내역을 거래처별 미수채권(AR)으로 집계 → 연령분석(aging) → 독촉 초안으로
만드는 스키마·규칙·산출물 명세. 양식 구조는 실제 서식(비즈폼/예스폼 **미수채권 관리대장**
+ 매입매출장 통합관리 **거래처원장(미수)**)을 기준으로 했다. 회사별 여신정책·회계정책과
다를 수 있고, 대손·대손세액공제·법적 조치 판단은 세무대리인·법무가 확인한다.

---

## 1. 미수채권 관리대장 스키마

출처: 비즈폼/예스폼 미수채권 관리대장. 대장 헤더에 **작성자**를 둔다(`작성자` 메타).
1행 = 1채권(또는 1거래) 기준으로 정규화한다.

| 컬럼 | 설명 | 비고 |
|------|------|------|
| 거래일자 | 채권 발생일(매출일/청구일) | YYYY-MM-DD, 세금계산서 작성일과 대조 |
| 거래처명 | 정규화된 상호 | 사업자번호 있으면 함께 |
| 담당자 | 거래처 채권 담당자 | 거래처 마스터에서, 없으면 [확인 필요] |
| 전화번호 | 거래처 담당자 연락처 | 독촉 안내 대상, 마스킹 최소 노출 |
| 미수금액 | 해당 채권의 미상환 잔액 | 부분입금 반영 후 잔액 |
| 변제(예정)일 | 약정 변제일/입금 예정일 | 경과일수·연체 판정 기준 |
| 어음/수표번호 | 어음·수표 결제분 식별 | 만기일 함께(있으면) |
| 비고 | 분쟁·이의·부분입금·[확인 필요] 메모 | 충돌·미확정 사유 |

---

## 2. 거래처원장(미수) 스키마

출처: 매입매출장 통합관리 거래처원장(미수). 거래처별 1행으로, 기간 내 채권 증감을
이월·매출·입금·잔액으로 요약한다. §1 관리대장이 건별이라면 이 표는 거래처별 합계다.

| 컬럼 | 설명 | 비고 |
|------|------|------|
| 거래처 | 상호(+사업자번호) | §1과 거래처 키 일치 |
| 전기이월 | 기초 미수잔액 | 직전 기간 이월액, 없으면 [확인 필요] |
| 당월 매출 | 기간 내 발생 채권 합계 | 공급가액+세액(청구금액) |
| 당월 입금 | 기간 내 회수액 합계 | 매칭된 입금만 |
| 미수잔액 | 전기이월 + 당월 매출 − 당월 입금 | 검산값, §1 미수금액 합과 대조 |

### 입금 매칭 규칙 (은행 입금내역 ↔ 미수)

- 거래처(예금주/적요), 금액, 일자가 명확히 일치할 때만 해당 채권에서 자동 차감한다.
- **자동 확정하지 않고 [확인 필요]로 남기는 경우**: 부분입금(금액 불일치), 한 입금이
  복수 채권에 걸침, 예금주명이 거래처와 달라 모호, 입금 후보가 2건 이상, 어음 만기 전 입금.
- 매칭된 입금은 `출처`로 추적 가능하게 기록한다. 충돌 건은 차감하지 말고 비고에 사유를 적는다.
- 과오납·선수금(채권보다 많은 입금)은 미수에서 빼지 말고 별도 [확인 필요]로 분리한다.

---

## 3. 연령분석(aging) 버킷 테이블

기준일(as-of date) 현재 미상환 채권을 경과일수 구간으로 버킷팅한다. 경과일수는
**변제(예정)일 기준**(있으면), 없으면 **거래일 기준**으로 계산하고 어느 기준인지 표에 명시한다.

| 컬럼 | 설명 | 비고 |
|------|------|------|
| 거래처 | 상호(+사업자번호) | |
| 미수잔액 | 거래처 총 미수금액 | 구간별 금액 합과 일치(검산) |
| 최장 경과일수 | 가장 오래된 미상환 채권의 경과일수 | 기준일 − (변제일 또는 거래일) |
| 0–30 | 0~30일 구간 금액 | 정상~초기 |
| 31–60 | 31~60일 구간 금액 | 주의 |
| 61–90 | 61~90일 구간 금액 | 연체 |
| 90+ | 90일 초과 구간 금액 | 장기연체, 회수불능 추정 후보 |
| 연체여부 | 연체/정상 | 변제일 경과 시 연체 |

### 규칙

- 구간 경계(30/60/90)와 기준일(as-of date)을 표 상단에 명시한다.
- 한 거래처에 여러 채권이 있으면 채권별로 구간에 배분하고, 거래처 행은 구간별 합계로 표시한다.
- `90+` 장기연체는 **회수불능 추정 후보**로만 표시한다. 대손 확정·대손세액공제 판단은
  세무대리인 몫이며 이 스킬에서 확정하지 않는다.
- 분쟁/이의 제기 중인 채권은 aging에는 포함하되 `연체여부`를 [확인 필요]로 두고 독촉 대상에서 뺀다.

---

## 4. 독촉/안내 메일 초안 구조

연체 거래처별로 정중한 입금 안내 초안을 만든다. **발송하지 않는다 — 초안까지만.**
톤은 관계 유지가 default(거래 지속 의사 전제). 위협·법적 단정·과장 표현은 넣지 않는다.

| 요소 | 내용 | 비고 |
|------|------|------|
| 수신/거래처 | 거래처명·담당자 | §1 거래처명·담당자 |
| 미수 금액 | 청구·미상환 금액 | 세금계산서 번호/거래일 근거 함께 |
| 기일 경과 | 변제(예정)일과 경과일수 | §3 최장 경과일수 인용 |
| 본문 톤 | 정중한 안내 — 확인 요청 + 입금 협조 부탁 | 관계 유지, 분쟁 건 제외 |
| 입금계좌 | 회사 지정·확인된 계좌 | 임의 생성 금지, 없으면 [확인 필요] |
| 문의처 | 회사 담당자·연락처 | 이의/분할 상환 문의 경로 안내 |

### 규칙

- 금액·기일경과는 §1/§3 집계값을 그대로 인용하고, 원본에 없는 수치는 [확인 필요]로 둔다.
- 경과 정도에 따라 톤만 단계화(초기: 확인 요청 → 장기: 협조 강하게 요청)하되, 법적 조치
  예고·내용증명 문구는 넣지 않는다(별도 사람·법무 결정).
- 분쟁/이의 제기 중인 거래처는 독촉 초안을 만들지 않고 `[확인 필요] 분쟁 중`으로 분리한다.

## 5. 발송 전 검수 체크 (사람 확인)

- [ ] 입금 매칭이 올바른가(과차감·미차감 없음, 부분입금·복수 채권 충돌은 [확인 필요] 분리)
- [ ] 거래처원장 미수잔액(= 전기이월 + 당월 매출 − 당월 입금)이 관리대장 미수금액 합과 일치
- [ ] aging 구간별 금액 합 = 거래처 미수잔액(검산), 기준일·구간 경계 명시
- [ ] 경과일수 기준(변제일 / 거래일)이 산출물에 표시됨
- [ ] 분쟁/이의 중인 채권이 독촉 대상에서 제외됨
- [ ] 독촉 초안 톤이 관계 유지 수준이고 위협·법적 단정 문구 없음
- [ ] 입금계좌·문의처가 회사 지정·확인 값인가(임의 생성 없음)
- [ ] 민감정보(사업자번호·계좌·연락처) 노출 최소화
- [ ] **독촉 메일·법적 조치 발송은 사람 승인 후** — 이 산출물은 초안
- [ ] **대손 처리·대손세액공제 판단은 세무대리인** — 90+ 장기연체는 회수불능 추정까지만
