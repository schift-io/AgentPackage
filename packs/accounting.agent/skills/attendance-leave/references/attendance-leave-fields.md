# 근태표 · 연차관리대장 필드 명세 (Room821 자체 양식)

비즈폼/예스폼 연차관리대장 + 월 근태관리대장 서식의 항목/구조를 참고해 재구성한 우리
양식. document-helper가 html/xlsx로 렌더링할 때 이 필드를 채운다. **외부 파일을 그대로
쓰지 않고 항목/구조만 참고해 새로 만든다.** (출처: 비즈폼·예스폼 연차관리대장 / 근태관리대장)

## 1. 근태 코드 (일자별 셀 값)

| 코드 | 의미 | 비고 |
|------|------|------|
| 출 | 정상 출근 | |
| 지 | 지각 | 사유·승인 여부 별도 표기 |
| 조 | 조퇴 | 사유·승인 여부 별도 표기 |
| 결 | 결근 | 무단/승인 구분은 자동 단정 금지 [확인 필요] |
| 연차 | 연차휴가(1일) | 연차대장 사용분과 연동 |
| 반차 | 반차(0.5일) | 오전/오후 구분 |
| 연장 | 연장근로(시간 기입) | 소정근로시간 초과분, 시간 단위 |
| 야간 | 야간근로(시간 기입) | 야간시간대 근로, 시간 단위 |
| 휴 | 휴일/공휴일 | 휴일근로 시 시간 별도 |
| 출장 | 출장 | 근무일수에 포함 |

| 필드 | 설명 | 비고 |
|------|------|------|
| 사번 | 사원 식별자 | |
| 부서 | 소속 부서 | |
| 직위 | 직급/직위 | |
| 성명 | 사원명 | 개인정보 최소화 |
| 대상 연월 | YYYY-MM | |

## 3. 월 근태표 — 일자별 (행 단위 = 사원, 열 = 일자)

| 필드 | 설명 | 비고 |
|------|------|------|
| 1~31일 셀 | 일자별 근태 코드(위 §1) | 연장·야간은 시간 수 기입 |
| 출근시각 / 퇴근시각 | 기록상 시각 | 연장·야간 산정 근거 |
| 지각/조퇴 사유 | 사유 + 승인 여부 | 급여 공제·징계 연결, 단정 금지 |

## 4. 월 근태표 — 월계 (집계)

| 필드 | 설명 | 회계/급여 처리 |
|------|------|----------------|
| 근무일수 | 실 출근(출장 포함) 일수 | |
| 지각 횟수 / 조퇴 횟수 | | 급여 공제 정책은 회사 규정 [확인 필요] |
| 결근일수 | 결근 일수 | **급여 공제 입력** (공제액 환산은 급여 스킬) |
| 연차 사용일수 | 연차+반차 환산 | 연차대장 사용분과 일치해야 함 |
| 연장근로시간 | 월 합계(시간) | **가산 입력** (가산율·금액은 급여 스킬) |
| 야간근로시간 | 월 합계(시간) | **가산 입력** (가산율·금액은 급여 스킬) |
| 휴일근로시간 | 월 합계(시간) | 가산 입력 |
| 특기사항 | 충돌·누락·확인필요 메모 | |

| 필드 | 설명 | 비고 |
|------|------|------|
| 부서 | 소속 부서 | |
| 직위 | 직급/직위 | |
| 성명 | 사원명 | |
| 입사일 | YYYY-MM-DD | **산정 기준이 입사일이면 기준점** |
| 근속연수 | 입사일 기준 산정 | 발생 일수 산정에 영향 |

## 6. 연차 관리대장 — 산정 (사원별 행)

> **산정 기준 라벨 필수**: [ ] 입사일 기준  [ ] 회계연도 기준 → **어느 기준인지 [확인 필요]**.
> 두 기준은 발생 일수·정산 시점이 달라 결과가 다르다. 기준 미정 시 가정 라벨을 붙여 초안만 낸다.

| 필드 | 설명 | 산정 처리 |
|------|------|-----------|
| 산정 기준 | 입사일 기준 / 회계연도 기준 | **[확인 필요] — 사람/노무대리인 확정** |
| 산정 기간 | 발생 대상 기간(YYYY-MM-DD~) | 기준에 따라 다름 |
| 발생 연차 | 해당 기간 발생 일수 | 발생 일수 **단정 금지**, 기준·근속 표기 후 [확인 필요] |
| 사용 연차(연차) | 1일 단위 사용분 | 근태표 연차와 일치 |
| 사용 연차(반차) | 0.5일 단위 사용분 | 근태표 반차와 일치 |
| 사용 합계 | 연차 + 반차 환산 | 자동 합산 |
| 잔여 연차 | 발생 − 사용 | 발생이 [확인 필요]면 잔여도 잠정 |
| 미사용 연차 | 정산 시점 미사용 일수 | 연차촉진 통보 여부 표기 |
| 미사용수당 | 미사용 × 통상임금 환산 | **수당 산정 단정 금지** — 노무/급여 확인 [확인 필요] |
| 비고 | 연차촉진·중도입퇴사·기준 충돌 메모 | |

## 7. 급여 반영용 근태 집계 (withholding-payroll 입력)

> 시간·일수만 확정한다. **금액 환산(가산수당·공제액)은 급여 스킬에서.** 일반 원칙만 제시.

| 필드 | 설명 | 비고 |
|------|------|------|
| 사번 / 성명 | 사원 식별 | |
| 대상 연월 | YYYY-MM | |
| 연장근로시간 | 월 합계 | 통상 가산 대상(원칙) — 가산율·금액은 급여 스킬 |
| 야간근로시간 | 월 합계 | 통상 가산 대상(원칙) — 가산율·금액은 급여 스킬 |
| 휴일근로시간 | 월 합계 | 가산 대상(원칙) |
| 결근일수 | 월 합계 | 급여 공제 입력 — 공제액은 급여 스킬 |
| 연차 사용일수 | 월 합계 | 유급 처리 — 공제 아님 |
| 비고 | 한도 위반 의심·확인필요 | 근로시간 한도 위반 여부 단정 금지 [확인 필요] |

## 8. 확정 전 검수 체크 (사람 확인)

- [ ] **연차 산정 기준(입사일 vs 회계연도)을 사람/노무대리인이 확정** — 가장 중요
- [ ] 발생 연차 일수가 확정 기준·근속연수와 맞는지 (노무대리인 검토)
- [ ] 근태표 연차/반차 사용분과 연차대장 사용분 일치
- [ ] 출퇴근 시각 기준 연장·야간 시간 산정이 회사 소정근로시간 규정과 맞는지
- [ ] 결근·지각·조퇴의 무단/승인 구분 및 사유서 확인 (자동 단정 금지)
- [ ] 미사용수당 산정·연차촉진 통보 여부 (노무/급여 확인)
- [ ] 급여 반영 집계의 가산·공제 시간·일수가 정확한지 (금액 환산은 급여 스킬)
- [ ] 같은 날짜의 휴가신청·출근기록 충돌 해소
- [ ] 개인정보(주민번호·연락처) 마스킹
