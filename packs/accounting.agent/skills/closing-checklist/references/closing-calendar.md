# 월마감 체크리스트 · 세무/4대보험 기한 캘린더 (Room821 자체 큐레이션)

마감 관제 스킬이 점검·알람 항목을 구성할 때 쓰는 일반 기준. **신고·납부 기한은
연도별·공휴일·말일에 따라 이동하므로 아래 날짜는 일반론이며, 정확 일자는 반드시
[확인 필요] + 홈택스/위택스 확인이 필요하다.** 실제 마감·전기·신고는 담당자/세무대리인.

---

## 1. 마감 체크리스트 (영역별)

마감 시점에 각 영역을 체크박스로 점검한다. 미완료 항목은 건수·금액과 함께 노출.

### 거래 (ledger)
- [ ] 미분류 거래(계정과목 미지정) 0건인가 — 남아 있으면 건수·금액 표시
- [ ] 중복 의심 거래(은행·카드·영수증 중복) 정리됐는가
- [ ] 금액·일자 충돌로 "검토 필요"로 남은 거래 처리됐는가
- [ ] 기간 내 모든 통장·카드 명세가 반영됐는가 (누락 계좌/카드 없는지)

### 증빙 (expense)
- [ ] 3만 원 초과(접대비 3만/경조사비 20만 초과) 거래에 적격증빙 있는가 → **없으면 증빙불비 가산세 위험**
- [ ] 적격증빙(세금계산서·계산서·카드매출전표·현금영수증) 매칭 안 된 지출 0건인가
- [ ] 공급처 상호 + 사업자등록번호 미확인 증빙 정리됐는가

### 미수금 (receivables / AR)
- [ ] 미발행 (전자)세금계산서 없는가 (매출 누락 → 부가세·매출 누락 위험)
- [ ] 입금 대사(매출↔입금) 미완료 건 정리됐는가
- [ ] 장기 미수·대손 의심 채권 표시했는가

### 미지급 (payables / AP)
- [ ] 미지급비용·미지급금 계상 누락 없는가 (월 귀속 비용 반영)
- [ ] 매입 (전자)세금계산서 수취 누락 없는가 (부가세 매입공제 누락 위험)
- [ ] 선급비용·미지급 정산 항목 정리됐는가

### 급여·원천 (withholding)
- [ ] 급여대장 확정 + 4대보험 공제 반영됐는가
- [ ] 원천징수 대상(근로/사업 3.3%/기타 8.8%/일용) 누락 없는가
- [ ] 원천세·지급명세 신고 기한 임박 항목 캘린더에 올렸는가

### 세무 (vat / 결산)
- [ ] 부가세 매입·매출 집계 일치(공급가액+세액 검산)하는가
- [ ] 부가세 불공제 항목(접대비·비영업용 승용차·면세) 분리됐는가
- [ ] 미마감 계정(가지급금·가수금·미결산 잡손익) 정리됐는가
- [ ] 다가오는 신고 기한이 캘린더에 반영됐는가

**원칙**: 비어 있는 영역(미산출)은 "정상"이 아니라 **마감 리스크**로 표시. 가산세
위험 항목은 별도 "위험" 라벨로 분리. 가산세 금액은 단정하지 않는다(세무대리인 판단).

## 2. 세무·4대보험 신고/납부 기한 캘린더 (일반론)

아래 날짜는 **일반 기준**이며 공휴일·말일·연도 변동으로 이동한다 → 정확 일자 [확인 필요].

### 부가가치세 (일반과세자)
| 구분 | 신고·납부 기한(일반) | 비고 |
|------|----------------------|------|
| 1기 예정 | **4/25** | 법인. 개인 일반은 예정고지(고지서) |
| 1기 확정 | **7/25** | 1~6월분 |
| 2기 예정 | **10/25** | 법인. 개인 일반은 예정고지 |
| 2기 확정 | **다음해 1/25** | 7~12월분 |

- **간이과세자**: 연 1회, **다음해 1/25** (직전연도 1~12월분).
- **준비물**: 매입/매출 집계, (전자)세금계산서·계산서, 신용카드 매출·매입 집계,
  현금영수증, 불공제 항목 분리표.

### 원천세 (원천징수이행상황신고)
| 구분 | 기한(일반) | 비고 |
|------|-----------|------|
| 매월 징수분 | **다음달 10일** 신고·납부 | 원칙 |
| 반기납부 특례 | 상반기 **7/10** · 하반기 **다음해 1/10** | 특례 승인 사업자만 |

- **준비물**: 급여대장, 원천징수 내역(근로/사업 3.3%/기타 8.8%/일용), 공제·납부세액 집계.

### 지급명세서 / 간이지급명세서
| 구분 | 제출 기한(일반) | 비고 |
|------|-----------------|------|
| 근로·사업·기타소득 지급명세서 | **다음해 3/10** | 연 단위 |
| 간이지급명세서 | 매월/반기 등 소득별 상이 | 소득 종류에 따라 [확인 필요] |

- **준비물**: 수령자별 지급액·원천징수액, 사업소득·근로소득 구분 집계.

### 4대보험
| 구분 | 시점(일반) | 비고 |
|------|-----------|------|
| 보수총액신고 | 연초(예: 3월경) | 건강·고용·산재 등 |
| 보험료 정산·월별 | 월별 정산 | 입퇴사·보수 변동 반영 |

- **준비물**: 전년도 보수총액, 가입자별 보수월액, 입퇴사·변동 내역. 정확 일정은
  공단 공지에 따라 이동 → [확인 필요].

### 종합소득세 (개인)
| 구분 | 기한(일반) | 비고 |
|------|-----------|------|
| 종합소득세 신고·납부 | **5/31** | 성실신고 대상은 6/30 |

- **준비물**: 연간 수입·비용 집계, 적격증빙, 원천징수영수증, BS·PL, 공제 자료.

### 법인세
| 구분 | 기한(일반) | 비고 |
|------|-----------|------|
| 법인세 신고·납부 | 사업연도 종료 후 **3개월 이내** | 12월 결산 법인 → **3/31** |

- **준비물**: 결산 재무제표, 세무조정 자료, 적격증빙, 가지급금·가수금 정리.

### 연말정산
| 구분 | 시점(일반) | 비고 |
|------|-----------|------|
| 근로소득 연말정산 | **다음해 2월 급여 지급분**에 반영 | 환급/추징 정산 |

- **준비물**: 근로자별 소득·세액공제 자료(간소화 자료), 부양가족·기부금·의료비 등.

## 3. 알람 산정 원칙

- 기준일(today) 기준으로 다가오는 기한을 D-day로 정렬하고, 임박(예: D-7 이내)
  항목을 상단에 노출한다.
- 사업자 유형·과세 유형·반기납부 특례·결산월에 따라 해당되는 기한만 추린다.
  조건 미확인 시 [확인 필요]로 남기고 후보를 모두 표시.
- **모든 확정 일자·공휴일 이동은 [확인 필요] + 홈택스/위택스 확인 권고**로 닫는다.
  스킬이 단정 일자를 제시하지 않는다.
- 마지막은 항상 "마감 확정 전 담당자/세무대리인 검토 필요"로 마무리.
