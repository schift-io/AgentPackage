# Withholding Payroll (원천세·급여 — 지급내역→급여대장·원천징수 집계·명세서 초안)

## Purpose

급여·외주비 지급 내역에서 ① **급여대장**(간이세액표 원천징수 + 4대보험 공제 →
실지급액), ② **사업소득 3.3%·기타소득 8.8%·일용직 원천징수 집계**, ③ **지급명세서·
원천징수영수증 초안**을 한 묶음으로 만든다.

`ledger-automation`이 "기간 단위 거래내역 → 장부·세무 리포트"라면, 이 스킬은
"지급 대상자 명단 → 급여대장·원천세 집계·명세서 초안"이다. 입력은 지급내역(급여·
외주비), 출력은 1인별 원천징수 계산과 신고용 명세서 구조다.

## Inputs

- 사용자 한 줄 요청 (예: "3월 급여대장 만들어줘", "외주 5건 3.3% 떼고 지급명세 정리")
- 지급 자료: 급여 지급내역(성명·지급항목·금액), 외주·강사료 지급내역, 일용직 출역대장,
  근로/사업소득 구분 표시, 부양가족 수·공제대상 자녀 수(간이세액표 적용용)
- 대상 기간: 월(급여) / 지급일 기준(사업·기타소득) / 반기·연 단위(지급명세서)
- 적용 연도: **간이세액표·4대보험 요율·세율은 연도별로 바뀜** → [확인 필요]로 명시
- 사업자 유형: 개인사업자 / 법인 (징수의무자 정보 분기)
- 회사 급여규정·비과세 항목 한도 (식대·보육수당 등, default 회사 버킷)

## 사용 전 intake

한 번에 1~3문항씩 확인한다. 다 모르면 [확인 필요]로 두고 진행한다.

- 소득 종류 (근로소득 / 사업소득 3.3% / 기타소득 8.8% / 일용직)
- 적용 연도 (간이세액표·보험요율 버전) — **반드시 확인, 모르면 [확인 필요]**
- 목표 산출물 (급여대장 / 원천세 집계표 / 지급명세서 / 원천징수영수증 초안)
- 1인별 공제 정보 (부양가족 수·자녀 수, 비과세 항목·한도)
- 신고·제출 예정 여부 (원천세 신고 / 지급명세서 제출 / 세무·노무대리인 검토)

## Pipeline (단계)

1. **소득 분류** — 지급 건마다 근로/사업/기타/일용직 중 어느 소득인지 입력값 기준으로
   분류. 분류 근거를 남기고, 애매하면 자동 확정하지 말고 [확인 필요](노무 판단 영역).
2. **원천징수 계산** — 소득별 세율 적용.
   - 근로소득: 간이세액표(부양가족·자녀 기준) → 소득세 + 지방소득세(소득세의 10%).
   - 사업소득: 3.3%(소득세 3% + 지방소득세 0.3%).
   - 기타소득: 8.8%(필요경비 60% 인정 기준, 소득세 8% + 지방소득세 0.8%).
   - 일용직: 일 15만 원 공제 후 6.6%(소득세 6% + 지방 0.6%).
   - 적용 세율·표 버전을 계산 옆에 명시.
3. **4대보험 공제(근로소득)** — 국민연금·건강보험·장기요양·고용보험을 적용 연도
   요율로 공제. 요율 버전을 명시하고, 가입 여부 자체는 노무 판단 → [확인 필요].
4. **실지급액 산출** — 지급총액 − (원천세 + 4대보험) = 차인지급액(실지급액).
5. **집계·명세서 초안** — 1인별/소득종류별 합계, 지급명세서·원천징수영수증 초안.

세부 필드·세율표·집계 컬럼은 references/payroll-withholding-fields.md.

## Rules

- **노무 판단(근로/사업소득 구분, 4대보험 가입대상 여부, 일용/상용 구분)과 원천세
  신고·지급명세서 제출은 사람/세무·노무대리인의 몫이다.** 이 스킬은 **집계와 명세서
  초안까지만** 한다. 판단이 갈리는 지점은 후보 + [확인 필요]로 남기고 확정하지 않는다.
- **간이세액표·4대보험 요율·세율은 연도별로 바뀐다.** 적용 연도를 산출물에 [확인 필요]로
  명시하고, 어느 표/요율 버전을 썼는지 계산마다 함께 남긴다. 연도 미상이면 계산 보류.
- 입력에서 확인되는 사실만 적는다. 성명·주민번호·지급액·지급일·부양가족 수가 없으면
  [확인 필요]로 표시하고 지어내지 않는다.
- 원천세는 항상 **소득세 + 지방소득세(소득세의 10%)**를 분리 표기한다. 농어촌특별세
  대상이면 별도 표기. 합계만 적고 끝내지 않는다.
- 기타소득 8.8%는 필요경비 60% 인정 기준(과세표준=지급액×40%)임을 명시한다. 경비
  인정률이 다른 항목(상금·위약금 등)은 자동 적용하지 말고 [확인 필요].
- 일용직은 일 15만 원 공제 후 6.6%이며 소액부징수(세액 1,000원 미만) 가능성을 표시한다.
- 주민등록번호 등 민감정보는 생년월일 앞 6자리 + 뒤 1자리만 노출하고 나머지는 마스킹한다.
  계좌번호는 끝 4자리만 노출한다.
- 비과세 항목(식대·보육수당·연구보조비 등)은 회사 규정·연도별 한도를 확인해 과세/비과세를
  나누고, 한도 초과분은 과세로 표시한다. 한도 미확인 시 [확인 필요].
- 생성물은 **참고용 초안**이다. 원천세 신고·지급명세서 제출을 대체하지 않는다. 신고/제출
  전 세무·노무대리인 검토가 필요함을 산출물에 남긴다.

## 도구 경계

- 간이세액표·소득별 세율·4대보험 요율·비과세 한도는 `accounting-kr-tax-reference`
  버킷(schift-rag)을 먼저 검색하고, 검색된 근거(적용 연도 포함)를 계산 문장에 함께 남긴다.
  버킷에 해당 연도 값이 없으면 일반론 + [확인 필요]로 적용 연도 확인을 요청한다.
- 회사 급여규정·비과세 항목 한도·징수의무자 정보는 `default` 회사 버킷에서 확인한다.
  없으면 일반 기준 + [확인 필요]로 회사 규정 확인을 요청한다.
- 엑셀/CSV 파싱, 급여대장·집계표·명세서 렌더링, PDF 변환은 AWP의 document-helper
  노드가 처리한다. 이 스킬은 1인별 계산값과 명세서 구조를 정의한다.
- OCR/파싱 결과나 소득 분류가 충돌하면 자동 확정하지 않는다.

## Output Contract

- `format`: html / csv (+ document-helper로 xlsx·pdf 변환)
- 단계별 산출을 {id, title, bullets:[{claim, details[]}]} 구조로 반환한다.
- 급여대장·원천세 집계·지급명세서의 컬럼/필드는 references/payroll-withholding-fields.md를 따른다.
- 1인별 계산은 항상 **지급총액 / 원천세(소득세+지방) / 4대보험 / 실지급액**을 분리해 보인다.
- 마지막 섹션은 항상 "제출 전 검수 체크(사람 확인)"로 남기고, 원천세·지급명세서 신고
  기한 주의를 포함한다.
