# 원천세·급여 양식 필드 명세 (근로소득 원천징수영수증 · 급여대장 실측)

소득세법 시행규칙 [별지 제24호서식(1)] 근로소득 원천징수영수증/지급명세서(출처:
law.go.kr)와 급여대장(출처: 기업마당 무료서식)의 실제 필드를 확인해 재구성한 우리
양식. document-helper가 hwpx/html/xlsx로 렌더링할 때 이 필드를 채운다.
**외부 파일을 그대로 쓰지 않고 항목/구조만 참고해 새로 만든다.**

> **적용 연도 주의**: 간이세액표·4대보험 요율·세율은 연도별로 바뀐다. 아래 세율표는
> 일반론이며 실제 값은 적용 연도를 [확인 필요]로 확정하고 버킷에서 검색해 채운다.

## 3. 원천징수 세율 요약 (일반론 — 적용 연도 확인 필요)

> 세율·공제 기준은 연도별로 바뀐다. 적용 연도를 [확인 필요]로 확정하고 버킷 근거와 함께 쓴다.

| 소득 | 세율 | 과세표준 | 비고 |
|------|------|----------|------|
| 근로소득 | **간이세액표** | 월 급여 − 비과세 | 부양가족 수·자녀 수로 표 적용. 연말정산 별도 |
| 사업소득 | **3.3%** | 지급액 | 소득세 3% + 지방소득세 0.3% |
| 기타소득 | **8.8%** | 지급액 × 40% | 필요경비 60% 인정 기준. 소득세 8% + 지방 0.8% (지급액 기준 실효 8.8%) |
| 일용직 | **실효 약 2.97%** | (일급 − 15만 원) | 산출세액 = (일급−15만)×6%, **근로소득세액공제 55%** 적용 → 소득세 = 산출×45% = **(일급−15만)×2.7%** + 지방소득세(소득세의 10%). 소득세 1,000원 미만 소액부징수 면제 |

- ⚠️ **일용직을 단순 6.6%로 계산하지 말 것** — 55% 세액공제를 빼면 틀린다. 결정적 계산은 `accounting_compute.withholding(..., "daily")` 커널을 따른다.
- **소득세 + 지방소득세(소득세의 10%)**는 항상 분리 표기.
- 기타소득 경비 인정률이 다른 항목(상금·위약금 등)은 자동 적용 금지 → [확인 필요].
- 4대보험 요율(국민연금·건강·장기요양·고용)은 적용 연도 값을 버킷에서 확인해 채운다.

## 5. 제출 전 검수 체크 (사람 확인)

- [ ] **적용 연도**의 간이세액표·4대보험 요율·세율을 썼는지 (버전 명시)
- [ ] 소득 분류(근로/사업/기타/일용)가 맞는지 — **노무 판단은 세무·노무대리인 확인**
- [ ] 4대보험 가입대상 여부 — 노무 판단 영역, 자동 확정 금지
- [ ] 비과세 항목·한도(식대·보육수당 등) 과세/비과세 구분 적정
- [ ] 소득세 + 지방소득세(10%) 분리 계산, 합계 검산
- [ ] 기타소득 필요경비 60% 인정률이 항목에 맞는지
- [ ] 일용직 일 15만 원 공제·소액부징수 처리
- [ ] 주민번호·계좌번호 마스킹
- [ ] 지급총액 − (원천세 + 4대보험) = 실지급액 검산

### 신고·제출 기한 주의 (사람/세무대리인 확인)

- [ ] **원천세 신고·납부**: 원칙적으로 지급한 달의 **다음 달 10일**까지. 반기납부
      승인 사업장은 반기별. 적용 여부는 [확인 필요].
- [ ] **지급명세서 제출**: 소득 종류·시기별로 기한이 다름(근로·사업·기타소득, 간이지급
      명세서 포함). 정확한 제출 기한은 적용 연도 기준 세무대리인 확인 → [확인 필요].
- [ ] 기한 후 제출 시 가산세 위험 — 신고/제출은 세무·노무대리인이 최종 수행한다.
