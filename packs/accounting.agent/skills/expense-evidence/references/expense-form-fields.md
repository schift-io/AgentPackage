# 지출결의서 · 증빙 양식 필드 명세 (Room821 자체 양식)

bizinfo 기업업무용 서식 12종(아래 "bizinfo 실측 필드")을 rhwp/openpyxl/python-docx로
열어 실제 필드를 확인하고 재구성한 우리 양식. document-helper가 hwpx/html로 렌더링할
때 이 필드를 채운다. **외부 파일을 그대로 쓰지 않고 항목/구조만 참고해 새로 만든다.**

## 1. 지출결의서 헤더

| 필드 | 설명 | 비고 |
|------|------|------|
| 문서번호 | 지출결의 일련번호 | 회사 채번 규칙 있으면 따름, 없으면 [확인 필요] |
| 지출건명 | "20××년 ○월 지출 결의의 건" 등 | 실측: 지출결의서(특기사항) |
| 기안(발의)일자 | 작성일 | YYYY-MM-DD |
| 결재일자 | 결재 완료일 | 빈칸 가능 |
| 기안부서 | 지출 요청 부서 | |
| 기안자 | 작성자 성명 | |
| 결재선 | 담당 / 검토 / 승인 | 결재칸만 두고 서명은 사람 |

## 2. 지출 명세 (행 단위)

| 필드 | 설명 | 회계 처리 |
|------|------|-----------|
| No | 행 번호 | |
| 일자 | 지출 발생일 | 증빙 일자와 일치해야 함 |
| 계정과목 | 식대/여비교통비/복리후생비/소모품비/지급수수료/기업업무추진비(접대비) 등 | 분류 근거 명시 |
| 적요(내용) | 무엇을 위한 지출인지 | |
| 거래처(공급처) | 상호 + 사업자등록번호 | 적격증빙은 사업자번호 확인 |
| 결제수단 | 현금/법인카드/체크카드/계좌이체 (+ 카드·계좌 끝4자리) | 적격증빙·부가세공제 연결 (실측: 경비 지출현황표) |
| 수량 / 단가 | | |
| 공급가액 | 부가세 제외 금액 | |
| 세액 | 부가세 | 면세/불공제 표시 |
| 합계금액 | 공급가액 + 세액 | 자동 합산 |
| 증빙구분 | 세금계산서/계산서/카드매출전표/현금영수증/간이영수증/기타 | 적격 여부 |
| 부가세공제 | 공제/불공제 | 불공제 사유 |
| 상태 | 승인/반려/검토 | 실측: 지출결의서 관리대장 |
| 특기사항 | 충돌·누락·확인필요 메모 | |

## 3. 합계 요약 (관리대장형)

- 공급가액 합계 / 세액 합계 / 총 지출액
- 적격증빙 합계 / 비적격증빙 합계
- 부가세 공제대상 합계 / 불공제 합계
- **계정과목별 지출금액 집계** (실측: 대시보드 관리대장 — 식대/카드대금결제/비품구입/장비구입/기타지출 등)
- **월별 신청/지출 건수·금액** (다건 정리 시)

## 4. 증빙 첨부 목록 (영수증발급대장 변형)

실측: 영수증발급대장 = 발급일자 | 영수증번호 | 제목 | 내용 | 금액 | 수령일자 | 수령자 | 용도.

| 번호 | 증빙종류 | 거래처 | 일자 | 공급가액 | 세액 | 합계 | 파일명 | 적격여부 | 상태 |
|------|----------|--------|------|----------|------|------|--------|----------|------|
| 1 | 세금계산서 | … | … | … | … | … | … | 적격 | 확인 |
| 2 | 간이영수증 | … | … | … | — | … | … | 비적격 | 3만원 초과 [확인 필요] |

## 5. 제출 전 검수 체크 (사람 확인)

- [ ] 증빙 원본과 결의서 금액·일자·공급처 일치
- [ ] 3만 원 초과 지출 적격증빙 확보 (없으면 가산세 위험)
- [ ] 계정과목 분류가 회사 회계정책과 맞는지
- [ ] 부가세 불공제 항목(접대비/승용차/면세) 표시 적정
- [ ] 결재선·서명·날인
- [ ] 중복·누락 영수증 없음

## 부속 양식 (지출 외 — variant 확장 시 사용)

### 출장비 정산 (출장비용 지출결의서)
출장자(직위/성명) · 출장기간 · 출장지 · 연락처 · 출장목적 · 동행자(부서/직위/성명/전화) ·
출장비용(일금 원정) · 명세[구분|항목|사용내역|금액|비고] · 합계 · (영수증 첨부).

### 거래명세서 (거래조건·합계금액)
공급자(상호/대표자/사업자등록번호/소재지/업태/종목/담당자/연락처) · 공급받는자 ·
합계금액(VAT 포함) · 명세[날짜|품명|규격/단위|수량|단가|공급가액|세액|비고].

### 세금계산서 관리대장 (매입/매출 분리 — variant ③ 결제 추적)
부서명 · 작성자 · **매입**[일자|매입처(업체명)|품목|공급가액|부가세|합계] 매입 합계 ·
**매출**[일자|업체명|공급가액|부가세|합계] 매출 합계. 매입처별 내역표는 거래처별 집계.

### 회의경비 사용내역서 (증빙서류)
회의일자 · 회의명 · 회의장소 · 참석인원 · 사용경비 · 명세[항목|사용내역|금액(원)|비고].
