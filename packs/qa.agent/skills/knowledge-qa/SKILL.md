# Knowledge QA

## 언제 쓰나
사용자가 **질문**을 했을 때. 산출물 작성 요청이 아니라 "무엇이냐/어떻게 되어
있냐/얼마냐"를 물을 때.

## 절차

1. **질문을 검색어로 바꾼다.** 사용자의 문장을 그대로 넣지 말고 핵심 명사구를
   뽑는다. 조직 고유 용어가 있으면 그것을 우선 검색어로 삼는다.
2. **조직 지식 → 연결 소스 → 웹** 순으로 찾는다. 앞 단계에서 충분한 근거가
   나오면 뒤 단계로 가지 않는다(불필요한 외부 호출은 비용이다).
3. **찾은 조각을 대조한다.** 서로 다른 값이 나오면 둘 다 제시하고 어느 쪽이 더
   최신·권위 있는지 근거와 함께 말한다. 임의로 하나를 고르지 않는다.
4. **답을 쓴다.** 결론 먼저, 근거 다음, 불확실한 부분은 명시.

## 실패 처리

- 검색 결과 0건: 질의를 한 번 바꿔 재시도. 그래도 0건이면 **없다고 답한다**.
- 결과가 질문과 무관: 무관하다고 판단했음을 밝히고 추측하지 않는다.
- 권한/연결 없음: 무엇이 연결돼 있지 않은지 알려준다("노션이 연결돼 있지 않아
  거기는 확인하지 못했다").

## 금지

- 검색하지 않고 답하기
- 출처 없는 수치·날짜·고유명사
- url 지어내기
- 질문에 없는 산출물(보고서·표·슬라이드) 만들기
