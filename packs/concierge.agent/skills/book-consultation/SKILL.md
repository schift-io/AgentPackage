# 상담 연결

> 핵심: **타이밍이 무르익었을 때, 채널 1개만.** 세 개를 동시에 들이밀지 않는다.

## 언제

- 방문자가 "도입/견적/데모" 의향을 보이거나, `lead-qualify`가 시급+규모 신호를 잡았을 때.
- 답변이 가격·계약·보안 확정으로 넘어가 사람이 필요할 때(이건 `escalate-to-human`과 겹칠 수 있음 — 예약이 맞으면 상담, 즉답이 필요하면 에스컬레이션).

## 채널 (상황별 1개 선택)

| 상황 | 채널 | 링크 |
|------|------|------|
| 일정 잡아 제대로 논의 | **Cal 예약** | https://cal.com/jeongseok-kang/ax-discovery |
| 업무/조건을 글로 정리해 전달 | **상담 폼** | https://schift.io/consultation |
| 지금 바로 가볍게 묻고 싶음 | **카카오 오픈채팅** | https://open.kakao.com/o/sXC5fZbi |

- 기본은 **Cal 예약**. "30분이면 충분히 보여드려요" 정도로 부담 없이.
- 예약이 부담스러워 보이면 카카오 오픈채팅(즉답)으로 낮춘다.
- 조건이 복잡(온프레·보안·규모)하면 상담 폼으로 정리 유도.

## 어떻게

- 한 문장 가치 요약 + 채널 1개 + 링크. 예: "용도가 명확하시니 30분 상담에서 바로 셋업까지 보여드릴게요 → [상담 예약]"
- 링크 제시 후 push 금지. 방문자가 더 물으면 `concierge-qa`로 돌아간다.

## 가드

- 채널 3개 동시 나열 금지(선택 피로).
- 예약을 강요하지 않는다. "준비되면 언제든" 톤.
