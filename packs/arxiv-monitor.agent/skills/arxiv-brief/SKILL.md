# arXiv Brief Skill (관심 분야 논문 브리핑)

관심 분야(연구 주제/기술 키워드) 셋을 받아 arXiv 공개 API로 신규 등재 논문을 모으고,
중복·기보도분을 제거한 뒤 신규 논문만 관심 분야별 브리핑으로 만든다.

## 입력
- `research_interests` — 모니터링할 관심 분야/키워드 목록 (예: RAG, OCR, retrieval-augmented generation)
- `seen_ids` — 이전 브리핑에 이미 실린 `arxiv_id` 집합 (없으면 전체가 신규)
- `current_date` — 오늘 KST (inject-current-date가 주입)

## 데이터 소스 규칙
1. **발견은 arXiv API(`fetch_arxiv`)가 유일 소스.** `query`=관심 분야, `sortBy=submittedDate`(최신순)로 받는다.
2. 응답 필드: `title`·`arxiv_id`·`summary`(초록 전문)·`authors`·`published`·`updated`·`pdf_url`·`categories`.
3. **`summary`는 초록 전문이라 요약 근거로 충분하다.** 다만 초록에 없는 실험 수치·결론을 지어내지 않는다. 본문 전체 확인이 필요한 항목은 pdf_url을 "본문 확인 필요"로 남긴다.
4. 다른 논문 검색 사이트 크롤링·스크래핑 금지 — arXiv API만 쓴다.

## 처리 규칙
- **신규성**: `arxiv_id ∈ seen_ids`면 제외. 같은 논문의 개정판(v2, v3 등)은 최신 버전 1건으로 묶는다.
- **분류**: `published`/`updated` 기준 이전 브리핑 이후 등재분만. 관심 분야가 저빈도면 조회 기간을 완화한다.
- **주목 논문**: 같은 관심 분야에 다수 신규 논문이 몰리거나, 제목/초록에서 방법론적으로 눈에 띄는 논문을 최상단 하이라이트로 뽑는다.

## 출력 (HTML, 섹션 1~5)
1. **모니터링 조건** — 추적 관심 분야 목록 한 줄 요약.
2. **관심 분야별 신규 논문** — 분야마다: [제목](arXiv abs 링크) · 저자 · published 날짜 · 초록 기반 요약 3~5줄(핵심 기여·방법). 중복 개정판은 최신 버전만.
3. **주목 논문** — 이번 브리핑에서 두드러진 논문 하이라이트 (없으면 "특이사항 없음").
4. **신규 요약 통계** — 관심 분야별 신규 건수를 표로 정리한다.
5. **사람 확인 필요** — 본문 전체 확인이 필요한 항목(pdf_url), 초록만으로 판단이 애매한 것.

## 금지
- 초록에 없는 실험 결과·수치·인용 생성 금지.
- 같은 arxiv_id 재게시 금지(seen_ids 존중).
- arXiv API 외 소스 크롤링 금지.
