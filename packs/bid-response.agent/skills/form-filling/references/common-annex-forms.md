# 공공조달 공통 별지서식 (일반 패턴 — 공고마다 번호는 다를 수 있음)

PROOF.md 실측 기준으로 확인된 12종 산출물 구성 예시(IP-NAVI 공고 기준, 번호는
공고마다 다르게 매겨진다 — 원본 확인 필수):

1. 제안서 본문 (별도 산출)
2. 입찰참가신청서
3. 입찰보증금 관련 각서
4. 동의서
5. 확인서
6. 보안각서
7. 국가계약법 관련 서약서
8. 사용인감계
9. 제안서 표지
10. 제안업체 일반사항
11. 사업수행인력 현황
12. 개인정보 수집·이용 동의서

- 이 목록은 **참고 우선순위**일 뿐, 실제 채울 서식은 항상
  `requirement-scoring-map.required_forms`(RFP 원문 별지 번호)를 정본으로 한다.
- 서식 번호·명칭은 발주기관·공고마다 다르므로 하드코딩하지 않는다.
