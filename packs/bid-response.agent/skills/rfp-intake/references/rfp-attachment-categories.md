# RFP 첨부 카테고리 우선순위

나라장터 공고 아이템의 `ntceSpecFileNm1~10` 명칭 패턴으로 카테고리를 추정한다.
정확한 분류는 파일명·본문 첫 페이지 제목으로 재확인한다(자동 확정 금지, 애매하면
[확인 필요]).

| 우선순위 | 카테고리 | 파일명 패턴 예시 | 용도 |
|---|---|---|---|
| 1 | 제안요청서 (RFP) | `제안요청서`, `과업내용서` | 평가항목·배점·요구사항 원천 |
| 2 | 과업지시서 | `과업지시서`, `과업범위` | 상세 수행 범위·산출물 정의 |
| 3 | 공고서 | `입찰공고`, `공고문` | 입찰 자격·일정·제출 방법 |
| 4 | 별지서식 모음 | `별지`, `서식`, `양식` | form-filling 스킬 입력 |
| 5 | 계약서(안) | `계약서`, `과업수행계획서 양식` | 계약 조건 검토(사람 확인 영역) |
| 6 | 기타 참고자료 | `Q&A`, `설명회`, `붙임` | 보조 근거, 신뢰도 낮음 |

- 우선순위 1~3이 모두 확보돼야 요구사항 구조화(requirement-scoring-map)를 신뢰
  있게 진행할 수 있다. 하나라도 없으면 [확인 필요]로 남기고 계속 진행하되 산출물에
  "일부 첨부 미확보" 경고를 남긴다.
- HWP(구 포맷) 첨부는 `hwp_extractor.py` 경로로, PDF는 기존 OCR ingest 경로로
  처리한다(둘 다 기존 ingestion/extractors 재사용, 신규 파서 불필요).
