# Color Palettes (장표·카드뉴스 공용)

> 사용 규칙: 산출물 1건당 **아래 조합 중 1개만** 선택해서 쓴다. 조합을 섞거나 임의 색을 발명하지 않는다.
> accent 1색 원칙 — 강조색은 슬라이드/카드당 1개 요소 계열에만 쓴다 (diagram-design restraint 원칙).

## 0. 브랜드 기본 예시 (IR 장표용)

IR/사업발표 장표에서 고객 브랜드 키트가 없고 별도 지시도 없을 때만 쓰는 기준 예시다. 카드뉴스는 `brand_kit.key_color`를 우선하고, 이 조합을 고객 브랜드로 대체하지 않는다.

| 역할 | HEX | 용도 |
|---|---|---|
| accent (orange) | `#FF4D00` | 섹션 라벨, 키워드 하이라이트, CTA, 차트 주 시리즈 |
| paper (cream) | `#FAF7F2` | 슬라이드 배경 |
| ink | `#1A1A1A` | 본문/헤드라인 |
| panel (dark) | `#2B2A28` | 반전 패널, 차트 보조 시리즈 |
| card (white) | `#FFFFFF` | 카드 배경 (1px hairline 테두리) |

## 사용자 지정 조합 (2026-06-11 저장)

> 1~19번은 미전달. 19번의 잔여로 추정되는 단색 `#FDF9F3` 1건만 함께 기록.

| # | 이름 | 색 구성 |
|---|---|---|
| 19(부분) | (미상 — 배경 후보) | `#FDF9F3` |
| 20 | 핑크 레드 조합용 | `#FFB6C1` `#E83A31` |
| 21 | 감성적 네온 라임 | `#D4FF00` `#121414` `#FFFFFF` |
| 22 | 그린 주황 조합용 | `#00FF19` `#FF4D00` `#F2F2F2` `#000000` |
| 23 | 그린 레드 조합용 | `#1EB53A` `#B91C1C` `#FCF9F8` |

## 매체별 추천

- **IR/사업계획 장표**: 고객 브랜드 키트가 없으면 0번 브랜드 기본 예시. 기관 제출용은 채도 높은 네온(21·22·24) 금지.
- **카드뉴스(SNS)**: 고객 브랜드 키트 색상을 우선한다. 키트가 없을 때만 고대비 네온 계열(21, 24)이나 웰니스/친환경용 25·26을 선택한다.
- **대비 검증**: 텍스트/배경 조합은 WCAG AA(4.5:1) 미달이면 ink(`#121414`/`#000000`) 쪽으로 강제 교체.
