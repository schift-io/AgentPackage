# News Brief Skill (키워드 뉴스 브리핑)

키워드 셋을 받아 네이버 뉴스 검색 API로 최신 기사를 모으고, 중복·기보도분을 제거한 뒤
오늘(KST) 기준 신규 기사만 키워드별 브리핑으로 만든다.

## 입력
- `tracked_keywords` — 모니터링할 키워드 목록 (브랜드/경쟁사/업종/인물/종목)
- `seen_links` — 이전 브리핑에 이미 실린 `originallink` 집합 (없으면 전체가 신규)
- `current_date` — 오늘 KST (inject-current-date가 주입)
- `research_context` — (선택) web_search 글로벌 보강 결과

## 데이터 소스 규칙
1. **발견은 네이버 뉴스 검색 API(`fetch_news`)가 1차.** `query`=키워드, `sort=date`(최신순)로 받는다.
2. 응답 필드: `title`·`originallink`·`link`·`pubDate`·`description`(요약 스니펫). `<b>` 태그는 제거하고 읽는다.
3. **`description`은 본문이 아니다.** 스니펫 범위 안에서만 요약한다. 본문 전문이 필요하면 `originallink`를 "본문 확인 필요"로 표기 — 지어내지 않는다.
4. 글로벌/영문은 `web_search`로만 보강. 크롤링·셀레니움 금지.

## 처리 규칙
- **신규성**: `originallink ∈ seen_links`면 제외. 같은 사건 중복 보도는 가장 원본/공식 1건으로 묶고 "외 N건".
- **분류**: `pubDate` 기준 오늘/어제 발행을 우선. 7일 초과는 기본 제외(키워드가 저빈도면 완화).
- **속보/주목**: 같은 키워드에 단시간 다수 매체 보도가 몰리면 "주목 이슈"로 최상단.

## 출력 (HTML, 섹션 1~5)
1. **모니터링 조건** — 추적 키워드 목록 한 줄 요약.
2. **키워드별 신규 뉴스** — 키워드마다: [제목](originallink) · 매체 · pubDate · 스니펫 요약 3~5줄. 중복은 "외 N건".
3. **주목 이슈** — 보도 집중/속보 키워드 하이라이트 (없으면 "특이사항 없음").
4. **신규 요약 통계** — 키워드별 신규 건수 / 묶인 중복 수.
5. **사람 확인 필요** — 본문 확인 필요 항목, 미검증 출처, 스니펫만으로 판단 애매한 것.

## 금지
- 스니펫에 없는 수치·인용·사실 생성 금지.
- 같은 기사 재게시 금지(seen_links 존중).
- 크롤링/셀레니움/약관 위반 수집 금지.
