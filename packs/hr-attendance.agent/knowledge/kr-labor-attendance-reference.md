# 한국 근로기준법 근태 참고 자료 (요약)

> 법률 자문이 아닙니다. 구체적 사실관계에 따른 법 적용은 노무 전문가의 확인이 필요합니다.
> 상세 RAG 콘텐츠와 업로드 방법은 [README.md](./README.md)와 [rag-sources/](./rag-sources/)를 참조하세요.

## 연차유급휴가

- 1년간 80% 이상 출근한 근로자에게 15일 부여 (근로기준법 제54조)
- 3년 초과 시 2년마다 1일 가산, 최대 25일
- 1년 미만 근로자: 1개월 개근 시 1일
- 사용 시기는 원칙적으로 근로자가 신청, 사업주는 업무상 부득이한 경우 변경 가능
- 사용 촉진: 회사는 연차 사용을 촉진해야 함
- 미사용 연차 수당: 퇴직 시 미사용 연차에 대해 통상임금 기준 지급

## 근로시간

- 주 40시간, 1일 8시간 (근로기준법 제50조)
- 연장근로: 주 12시간 한도, 따라서 주 최대 52시간 (근로기준법 제52조)
- 연장근로 시 근로자 사전 동의 필요
- 50인 이상 사업장에 의무 적용
- 특례 업종: 별도 규정 적용

## 휴게시간

- 4시간 근무 시 30분 이상
- 8시간 근무 시 1시간 이상
- 휴게시간은 근로시간에 산입되지 않음

## 휴일

- 사용자는 근로자에게 1주간 평균 1회 이상 유급휴일 부여 (근로기준법 제56조)
- 휴일 근무 시 100% 가산 수당

## 야간·연장 가산

- 야간(22시~06시): 50% 가산
- 연장: 50% 가산
- 휴일에 야간 또는 연장 시 중복 가산

## 대체공휴일

- 공휴일이 휴일(일요일)과 겹치면 다음 평일이 대체공휴일
- 삼일절, 광복절, 개천절, 한글날 등 적용
- 설날, 추석 등 명절에도 적용될 수 있음

## 회사별 확인 필요 사항

- 연차 발생 기준: 입사일 기준 vs 회계연도 기준
- 반차/반반차 단위 및 사용 가능 여부
- 연차 사용 시기 제한 및 이월 규정
- 대체공휴일 유급 휴일 지정 여부
- 휴일 근무 시 대체휴가 vs 가산수당 선택권
- 특례 업종이나 특수 근무형태(재량근로, 탄력근무 등) 적용 여부
