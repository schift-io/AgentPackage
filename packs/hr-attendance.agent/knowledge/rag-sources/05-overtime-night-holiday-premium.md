# 연장·야간·휴일 가산수당

> 법률 자문이 아닙니다. 가산수당 산정은 회사 규정, 임금체계, 노무 전문가 확인이 필요합니다.

## 1. 연장근로 가산수당 (근로기준법 제55조)

법정 근로시간을 초과하여 연장근로를 한 경우 통상임금의 50% 이상을 가산하여 지급해야 합니다.

- 연장근로 수당 = 통상임금 × 1.5배(통상임금 100% + 가산 50%)
- 야간(22시~06시) 연장근로는 추가 가산 적용

## 2. 야간근로 가산수당 (근로기준법 제55조)

밤 10시부터 다음 날 오전 6시까지의 근로에 대해 통상임금의 50% 이상을 가산하여 지급해야 합니다.

- 야간근로 수당 = 통상임금 × 1.5배(통상임금 100% + 가산 50%)
- 연장근로와 중복 시 추가 가산

## 3. 휴일근로 가산수당 (근로기준법 제56조)

휴일에 근로를 제공한 경우 통상임금의 100% 이상을 가산하여 지급해야 합니다.

- 휴일근로 수당 = 통상임금 × 2배(통상임금 100% + 가산 100%)
- 휴일에 야간 또는 연장근로를 한 경우 추가 가산 적용

## 4. 가산수당 중복 적용

- 야간 + 연장: 통상임금 100% + 연장 가산 50% + 야간 가산 50% = 200%
- 휴일 + 연장: 통상임금 100% + 휴일 가산 100% + 연장 가산 50% = 250%
- 휴일 + 야간: 통상임금 100% + 휴일 가산 100% + 야간 가산 50% = 250%
- 휴일 + 야간 + 연장: 통상임금 100% + 휴일 가산 100% + 야간 가산 50% + 연장 가산 50% = 300%

## 5. 통상임금 산정

통상임금은 근로자에게 정기적·일률적으로 지급되는 임금을 말합니다.

- 기본급
- 직무수당, 직급수당 등 정기적 수당
- 식대, 교통비 등 정기적으로 지급되는 수당(일부 제외 가능)
- 상여금, 초과근로수당 등은 제외될 수 있습니다.

## 6. 회사별 확인 필요 사항

- 임금 명세서의 통상임금 산정 기준
- 야간·연장·휴일 근무에 대한 별도 승인 절차
- 대체휴가와 가산수당 중 선택 가능 여부
- 월차정산, 주차정산 방식
- 특례 업종이나 재량근로제 등 특수 규정 적용 여부
