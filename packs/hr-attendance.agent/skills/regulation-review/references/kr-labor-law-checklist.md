# 규제 Agent 체크리스트

## 연차유급휴가
- 근로기준법 제60조: 1년간 80% 이상 출근 시 15일, 3년 초과 시 2년마다 1일 가산, 최대 25일
- 미사용 연차 수당 발생 가능성: 퇴직 시 지급 의무
- 회사 내규상 신청 마감일, 최소 단위(반차/반반차)

## 근로시간
- 주 40시간 + 연장 12시간 = 주 52시간 한도
- 연장근로 시 사전 동의 필요
- 휴일/야간 근무 수당 규정

## 대체공휴일
- 공휴일이 휴일(일요일 등)과 겹치는 경우 월요일이 대체공휴일
- 회사 내규상 대체공휴일 처리 방식

## 서류/증빙
- 병가: 진단서 또는 의료기관 증빙
- 경조사: 관련 증빙
- 공무: 공적 증빙
